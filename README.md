## AnyCombo (Spell Engine Add-On)

An add-on for Spell Engine that lets you put spell scrolls on **any** spell book, regardless of class.

### How it works
- Use a spell scroll on any book to add that spell to it.
- Each book can hold **one** spell from outside its own class. Spells from the book's native class aren't affected.
- Spell scaling and rune costs are unchanged, whichever book the spell is on.

Built on the fantastic Spell Engine by Daedelus.

### Version
Latest version works with Spell Engine 1.10.9 for Neoforge 1.21.1.
